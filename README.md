# Requirements

Before building the application, install:

- Node.js
- npm
- Rust
- Tauri prerequisites for your operating system

Tauri setup guide:

https://tauri.app/start/prerequisites/

---

# Installation

Install dependencies:

```bash
npm install
```

---

# Building

This project uses a custom build command.

Build the desktop application with:

```bash
npm run app:build
```

This command builds:

- the SvelteKit frontend
- the Tauri desktop application

> Do not use `npm run build` for desktop releases.  
> Use `npm run app:build` instead.

The final binaries will be generated by Tauri in:

```txt
src-tauri/target/release/
```
